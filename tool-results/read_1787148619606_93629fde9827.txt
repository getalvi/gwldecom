    82→### Key Design Patterns
    83→
    84→- **Error responses**: `{ error: string, code?: string }` with proper HTTP status (200, 201, 400, 401, 403, 404, 409, 500)
    85→- **Input validation**: Zod v4 schemas on all POST/PUT/PATCH endpoints
    86→- **Auth checks**: `getServerSession(authOptions)` with role-based access control (admin/staff/customer)
    87→- **Price security**: Order creation recalculates all prices server-side from database (never trusts client)
    88→- **Stock management**: Atomic `decrement` on order, `increment` restore on cancel/return
    89→- **Coupon validation**: Active, not expired, not started, max uses, per-user limit, min order amount
    90→- **Guest cart**: Session ID from `X-Session-Id` header or query param for unauthenticated users
    91→- **Audit logging**: All admin actions (product CRUD, order status, user updates, settings) logged to AuditLog
    92→- **No `'use server'`** in route.ts files (route handlers are server-side by default in Next.js)
    93→- **AI import**: Fire-and-fetch pattern using `z-ai-web-dev-sdk` web-reader + LLM for product extraction

   272→### Backend: AI Chat API (`/api/ai/chat`)
   273→
   274→**Request:** `{ messages: {role, content}[], userId?: string }`
   275→**Response:** `{ reply: string }`
   276→
   277→**Intent Detection (keyword-based, no extra LLM call):**
   278→- Order queries (`my order`, `tracking`, `order status`) → `getCustomerOrders` (requires userId)
   279→- Policy/return/refund/terms → `getStorePolicies` (FAQs + CMS policy pages)
   280→- Shipping/delivery → `getStoreSettings` (shipping methods, fees, free thresholds)
   281→- Categories → `getCategories` (hierarchical tree with product counts)
   282→- Product search (40+ keywords + 50+ product category terms) → `searchProducts` (Prisma full-text search)
   283→- Product ID references → `getProduct` (full detail with variants)
   284→- General/fallback → no tool context, pure conversational LLM response
   285→
   286→**6 Server-Side Tool Functions:**
   287→1. `searchProducts(query, limit)` — Prisma search on title/description/tags, returns formatted products with prices, stock, badges, and clickable links
   288→2. `getProduct(id)` — Full product detail with variants and images
   289→3. `getCategories()` — Hierarchical categories with child counts
   290→4. `getStoreSettings()` — Shipping methods, fees, free thresholds from StoreSetting + ShippingMethod tables
   291→5. `getCustomerOrders(userId)` — Last 5 orders with items, status, tracking number
   292→6. `getStorePolicies()` — FAQs from FAQ table + policy content from CmsPage table
   293→
   294→**LLM Integration:**
   295→- Uses `z-ai-web-dev-sdk` (ZAI class, default import) with `ZAI.create()` + `zai.chat.completions.create()`
   296→- Model: `deepseek-chat`, temperature 0.7, max_tokens 1024
   297→- System prompt instructs Nova AI persona: friendly shopping assistant, BDT currency, `#product/{id}` link format, security rules against prompt injection, policy on confidential info
   298→- Tool results injected into system prompt as structured context
   299→- Message history limited to last 10 messages for context window
   300→- Error handling: graceful fallback messages on any failure
