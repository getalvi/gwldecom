    82→    82→### Key Design Patterns
    83→    83→
    84→    84→- **Error responses**: `{ error: string, code?: string }` with proper HTTP status (200, 201, 400, 401, 403, 404, 409, 500)
    85→    85→- **Input validation**: Zod v4 schemas on all POST/PUT/PATCH endpoints
    86→    86→- **Auth checks**: `getServerSession(authOptions)` with role-based access control (admin/staff/customer)
    87→    87→- **Price security**: Order creation recalculates all prices server-side from database (never trusts client)
    88→    88→- **Stock management**: Atomic `decrement` on order, `increment` restore on cancel/return
    89→    89→- **Coupon validation**: Active, not expired, not started, max uses, per-user limit, min order amount
    90→    90→- **Guest cart**: Session ID from `X-Session-Id` header or query param for unauthenticated users
    91→    91→- **Audit logging**: All admin actions (product CRUD, order status, user updates, settings) logged to AuditLog
    92→    92→- **No `'use server'`** in route.ts files (route handlers are server-side by default in Next.js)
    93→    93→- **AI import**: Fire-and-fetch pattern using `z-ai-web-dev-sdk` web-reader + LLM for product extraction

   322→   322→### Key Architecture Decisions
   323→   323→
   324→   324→- **No function calling from SDK**: Tools implemented as server-side Prisma queries executed BEFORE the LLM call, results injected as context in the system prompt
   325→   325→- **Keyword-based intent detection**: No additional LLM call for intent — efficient and deterministic
   326→   326→- **Chat history in component state**: Not persisted (session-only), keeping the widget stateless
   327→   327→- **z-ai-web-dev-sdk default import**: SDK uses `import ZAI from 'z-ai-web-dev-sdk'` (default export) with `await ZAI.create()` factory method
   328→   328→- **Security-first system prompt**: Explicit rules against prompt injection, system prompt leakage, and confidential info disclosure
   329→   329→- **Hash-based navigation integration**: Product links use the SPA's `#product/{id}` format for seamless navigation
